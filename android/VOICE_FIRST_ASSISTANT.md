# 길잡이 0.9.4 · 위치·병원·전화 음성비서

현재 위치와 주변 병원은 음성으로 안내합니다. 아래의 주소·병원명은 사용 예시이며 실제 답변에는 휴대폰 위치와 검색 결과를 사용합니다.

- **“내 위치가 어디야?”** → “현재 위치는 대략 ○○시 ○○구 ○○로 부근이에요.”
- **“주변에 병원 있어?”** → 확인한 병원·의원 이름과 직선거리 약 몇 미터인지 읽습니다. 이동 경로의 거리와 진료 여부를 확인했다고 말하지 않습니다.
- **“전화해줘.”** → “누구에게 전화할까요?” → 이름을 말하면 “○○에게 전화할까요?” → 긍정 답변 후 발신을 요청합니다.

## 버튼으로 대화하기

**공개 0.9.4는 공개 0.9.3과 서명이 달라 기존 앱을 삭제한 뒤 설치해야 합니다.** 삭제하면 개인 키·설정·준비한 모델이 초기화되므로 키를 다시 입력할 준비를 하고 설치하세요.

처음에 마이크·위치·연락처·전화 권한, 선택한 Gemini/OpenAI 키와 사용할 한국어 음성을 준비합니다. 음성비서를 시작한 뒤 물리 버튼 한 번으로 녹음을 시작하고, 말이 끝나면 다시 눌러 전송합니다. 답변 중 버튼을 누르면 답변을 멈추고 새 말을 녹음합니다. 각 대화 차례에도 같은 버튼 방식을 사용합니다.

음성·질문 전송에는 선택한 AI의 인터넷과 API 사용량이 필요합니다. 텍스트 기기 명령과 현재 위치 버튼 자체에는 AI 키가 필요하지 않습니다. UNO 정식 v5와 기존 `ASSIST` 신호를 사용합니다.

## 전화 확인

1. “전화해줘”에는 먼저 **누구에게 전화할지** 묻습니다. “엄마에게 전화해줘”처럼 이름을 이미 말하면 해당 연락처를 찾습니다.
2. 휴대폰 연락처에서 확인한 **대상 이름을 읽고 “○○에게 전화할까요?”**라고 묻습니다.
3. 확인 질문이 끝까지 재생된 뒤, 다음 차례에 **“네”, “응 전화해줘”** 등 명시적인 긍정 답변이 와야 합니다.
4. “○○에게 전화할게요” 안내 뒤 시스템 전화 서비스로 발신을 요청합니다.
5. **“아니요”, “아니”, “취소”, “하지마”**에는 “전화하지 않을게요”라고 안내하고 발신하지 않습니다.

불명확한 답변, 중단되거나 재생하지 못한 확인 질문, 만료된 확인에는 발신하지 않고 다시 확인합니다. 음성 인식·통신 오류가 나면 기존 동의를 버리고 대상을 다시 묻습니다. 확인은 한 번만 사용하며 질문 재생 완료 후 최대 60초 동안 유효합니다. 연결 안내 도중에도 버튼으로 중단·취소할 수 있습니다. 같은 이름에 여러 번호가 있으면 임의로 고르지 않습니다. AI가 만든 답변에 전화 명령이나 번호가 있어도 실행하지 않습니다.

실제 연결은 휴대폰 전화 서비스·통화 권한·SIM·통신망에서 결정합니다. 통화가 연결됐다는 확인 없이 연결 성공을 말하지 않습니다.

## 위치와 주변 병원

현재 위치는 Android 위치 API로 받습니다. 주소는 Android 주소 서비스에서 먼저 확인하고, 실패하면 Nominatim 주소 조회를 시도합니다. 주소를 얻으면 그 주소를 읽습니다. 좌표만 있고 주소 조회가 실패하면 **주소를 확인하지 못했다고 음성으로 설명하고 재시도 방법을 알립니다.** 주소를 추측하지 않습니다.

병원 검색은 OpenStreetMap의 병원·의원·의사 시설 기록을 검색합니다. 통신·서버 오류나 빈 결과에는 예비 검색을 시도합니다. 확인된 이름과 좌표로 거리를 계산해 읽습니다. 요청 제한 오류에는 다른 서버를 이용해 제한을 우회하지 않습니다. 데이터가 없거나 조회가 실패해도 “주변에 병원이 없다”고 단정하지 않으며, 실패와 재시도 방법을 음성으로 안내합니다.

주소와 장소 이름을 확인하려면 인터넷과 해당 데이터 서비스가 필요합니다. GPS만으로 도로명이나 병원 이름을 만들어낼 수는 없습니다. 오차가 큰 대략 위치를 사용하면 음성으로도 알립니다.

주소·장소 조회는 사용자가 요청할 때만 좌표와 장소 종류를 외부 지도 서비스로 전송합니다. 기본 장소 검색은 Overpass, 예비 주소·장소 검색은 Nominatim을 사용하며 Nominatim 요청은 앱 프로세스에서 초당 한 번 이하로 제한합니다. 출처는 © OpenStreetMap contributors / ODbL입니다. 장소·주소 답변을 일반 AI 대화 기록에 넣지 않습니다. ElevenLabs를 사용하면 읽을 답변 문장은 해당 음성 서비스로 전송됩니다.

## 한국어 음성

Gemini/GPT 음성비서는 기존 고정 ElevenLabs 여자·남자 목소리를 사용하고, 실패하면 휴대폰 기본 한국어 TTS로 대체합니다. 기본 TTS는 설치된 오프라인 한국어 음성 중 시스템 기본 음성을 우선하고, 한 음성이 실패하면 다른 설치된 한국어 음성을 시도합니다. 설치되지 않은 음성을 준비 완료로 취급하지 않습니다. 한국어 음성이 없거나 모두 재생에 실패하면 확인을 받았다고 처리하지 않으며 전화하지 않습니다.

**로컬 장면 AI는 기본 TTS만 사용합니다.** 실제 휴대폰에 한국어 음성 데이터가 준비되어 있어야 합니다.

APK는 1,828,280,205바이트(약 1.83GB)이며 로컬 모델 두 파일을 포함합니다. SHA-256: `a06777226cc512c8dbeb4bc32b170505742eb0954e23077451e3f1f1389fcbe1`.

주소·병원 이름과 거리의 음성 답변 생성, 대상 이름을 묻는 대화, 완전한 음성 질문 완료 이후 긍정 확인, 부정·중단·만료·권한 거절·중복 발신 차단을 검사합니다. 음성 내용·확인 대화 검사는 재생 시작·완료를 모의해 흐름을 검증하며 실제 사람이 음성을 들은 검사로 표시하지 않습니다. 주소·장소 HTTP 검사는 모의 응답과 공식 API 요청 형식을 사용합니다.

실제 주소·장소 서비스의 응답, 사용자 휴대폰의 GPS 수신·연락처·SIM 연결·무선이어폰·한국어 음성 재생은 실기 확인이 필요합니다. [검증 기록](VOICE_FIRST_VALIDATION.json).
