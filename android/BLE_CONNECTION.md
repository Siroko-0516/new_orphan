# 0.9.1 · AI 실행과 독립적인 HM-10 연결

기존 버전에서는 실시간 AI 서비스가 자신의 BLE 연결을 열고, AI 중지 시 함께 닫았습니다. 수동 연결·실시간 분석·음성비서가 서로 다른 GATT 소유자를 사용하기도 했습니다. 0.9.1은 별도 보드 연결 서비스 하나가 GATT를 관리합니다.

- **BLE 검색 → HMSoft 선택 → 선택한 BLE 기기 연결**로 시작합니다. 개인 AI 키·마이크 권한 없이 BLE 연결과 TEST를 사용할 수 있습니다.
- 이후 사진 분석 완료·오류, 실시간 AI 중지, 음성비서 중지, Activity 화면 이동·종료는 보드 연결을 닫지 않습니다.
- 앱이나 보드 연결 알림의 **BLE 연결 해제**로 명시적으로 종료합니다. 같은 기기로 AI를 시작하거나 비서를 시작할 때 정상 GATT를 다시 만들지 않습니다.
- TEST와 AI 경고는 모두 실제 연결 중인 보드로 보냅니다. 카메라 설정에 BLE 주소가 없던 상태에서도 TEST를 다른 연결로 잘못 보내지 않습니다.
- 실제 연결이 끊어지면 서비스가 살아 있는 동안 약 10초 간격으로 다시 시도합니다. 끊어진 동안 TEST·모터 경고를 쌓아 두거나 재연결 뒤 과거 명령을 다시 보내지 않습니다.
- 물리 버튼의 `ASSIST`는 활성화된 음성비서로 전달합니다. 비서가 꺼져 있으면 버튼 신호 수신 상태만 표시하며 마이크를 자동으로 켜지 않습니다.

휴대폰 블루투스 끄기·보드 전원 차단·운영체제 강제 종료·제조사 절전 정책에 따른 단절까지 방지하는 기능은 아닙니다. 실행 중 보드 연결 알림이 표시됩니다. 강제 종료·재부팅 뒤 자동 연결하지 않습니다.

## UNO·서보 확인

현재 v3 배선은 **서보 신호 D2 / 버튼 S D3 / HM-10 TXD→UNO D0(RX) / UNO D1(TX)→분압→HM-10 RXD**입니다. [UNO 전체 코드](../arduino/hm10_sg90_button/README.md)를 참고하세요. D0·D1은 USB 업로드와 공유하므로 업로드할 때 통신선을 분리합니다.

USB 시리얼 모니터 9600 baud·새줄에서 TEST를 보냈을 때 L LED가 잠깐 켜지면 UNO의 명령 처리는 확인된 것입니다. 서보가 움직이지 않는다면 [서보 단독 시험](../arduino/sg90_d2_test/README.md)으로 확인합니다. 이 시험은 BLE·AI 없이 60→120→90도를 각각 2초씩 유지합니다. LED만 바뀌면 서보의 공급 전압·전류, 공통 GND, 신호 접촉, 서보 자체를 확인해야 합니다. 실물 동작은 소프트웨어 빌드 검사로 확인할 수 없습니다.

## API 사용량

ChatGPT 구독의 채팅 사용량과 OpenAI API의 결제·충전 잔액은 별개입니다. ChatGPT 구독 한도를 앱의 API 사용량으로 전환하지 않습니다. OpenAI Platform에 별도 API 잔액이 있다면 해당 API에 사용할 수 있지만, 이 앱 버전의 AI 공급자는 Gemini와 로컬 모델입니다. GPT API 공급자를 추가한 버전은 아닙니다.

Gemini HTTP 429는 요청·사용량 제한이며 모든 크레딧이 영구 소진됐다는 뜻은 아닙니다. HTTP 503은 서버 혼잡으로 별개입니다. 연결 오류 때문에 보드 연결을 끊지 않습니다.

## 검사 범위

JVM 회귀 검사는 Activity 종료·AI 중지·비서 중지 후 연결 유지, 같은 기기의 연결 재사용, 명시적 해제, 예상치 못한 단절 후 재연결, 모터 명령 재전송 억제, 연결된 보드로 TEST 전송을 확인합니다. 실제 Android 15 검사에서는 카메라·비서·화면 수명과 별도로 보드 포그라운드 서비스가 유지되는지 확인합니다. 에뮬레이터에는 실물 HM-10이 없으므로 실제 무선 링크·서보 동작을 검증했다고 주장하지 않습니다.
