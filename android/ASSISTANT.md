# 길잡이 0.9.2 · 버튼으로 녹음 시작·전송·답변 중단

길잡이 Android 앱에서 처리합니다. UNO는 버튼을 눌렀을 때 `ASSIST\n`을 보내고, 앱의 `TEST\n`·`OBSTACLE\n`을 받는 역할입니다. [정식 UNO v5](../downloads/Giljabi-UNO-HM10-SG90-v5.zip)를 그대로 사용하며 버튼 방식 변경을 위해 UNO 코드를 다시 올릴 필요는 없습니다. 모터 점검 코드의 `BUTTON: local servo test`가 보인다면 정식 v5를 먼저 업로드합니다. 물리 버튼은 음성비서 호출용이며 모터는 앱 TEST·AI 위험 신호로 움직입니다.

## 시작

새 동작은 0.9.2 앱에서 적용됩니다. 실제 공개 APK의 서명·파일 검증 결과는 배포 기록에서 확인합니다. 기존 앱 삭제는 키·설정·준비한 모델을 초기화하므로 설치 시 서명 호환 여부를 먼저 확인합니다.

1. 무선이어폰을 휴대폰에 연결합니다. HM-10은 이어폰과 별도로 BLE 데이터 통신만 합니다.
2. 길잡이의 **Gemini API 키 · 모델 설정**에 개인 키를 저장합니다. 기존 ElevenLabs 키·여자/남자 고정 음성 설정을 이어 사용하며, 키가 없거나 생성·재생이 실패하면 기본 한국어 TTS로 대체합니다. 로컬 카메라 AI는 계속 기본 TTS만 사용합니다.
3. **BLE 검색 → HM-10 선택 → 음성비서 시작**을 누릅니다. 마이크·주변 기기 권한을 허용합니다. HM-10 없이도 앱의 말하기 버튼으로 먼저 시험할 수 있습니다.
4. **위치·연락처·전화 권한 허용**을 눌러 필요한 기능의 권한을 허용합니다. 위치는 정확한 위치, 통화는 SIM과 전화 기능이 필요합니다. 권한을 거절한 기능은 안내 후 실행하지 않습니다.
5. UNO 물리 버튼 또는 앱의 **버튼 누르고 말하기**를 한 번 누릅니다. 시작음과 **녹음 중** 표시 뒤에 말합니다.
6. 말을 마치면 같은 버튼을 한 번 더 눌러 **녹음을 끝내고 전송**합니다. 이때 Gemini가 음성을 받아 답변합니다.
7. 답변 중 버튼을 누르면 재생 중인 답변과 미완료 요청을 취소하고 **새 녹음을 시작**합니다. 새 질문도 말한 뒤 버튼을 다시 눌러 전송합니다.

말소리로 답변을 자동 중단하지 않습니다. 녹음 중 조용해져도 자동 전송하지 않습니다. 답변이 끝나면 마이크를 닫고 다음 버튼을 기다립니다. 앱 버튼과 알림 버튼도 물리 버튼과 같은 동작이며, 화면의 버튼 문구가 현재 동작에 맞춰 바뀝니다. **녹음 끝내고 전송** 처리 중 중복 클릭은 두 번째 요청을 만들지 않습니다.

한 번에 최대 60초를 녹음합니다. 이 한도에 도달하면 녹음을 멈추고 보관하며, **버튼을 눌러야 전송**합니다. 너무 짧은 녹음은 전송하지 않고 다시 녹음하도록 안내합니다. 답변 재생·대기 중에는 녹음하지 않습니다. 이어폰 통신 경로는 녹음·응답까지 유지하고, 답변이 끝나면 오디오 경로를 해제합니다. 실제 이어폰 마이크·재생 경로는 기기에서 확인해야 합니다.

비서 대기 서비스는 화면이 꺼져도 유지되고 앱/알림의 비서 중지로 종료합니다. 비서·AI를 중지해도 별도 BLE 연결을 유지하며, 보드 연결은 앱/보드 알림의 BLE 연결 해제로 종료합니다. 제조사 절전·강제 종료·재부팅 뒤의 자동 실행은 보장하지 않습니다. 음성비서 동작 중 마이크 표시와 실행 알림이 나타납니다.

## 명령 예시

- **“엄마에게 전화해줘.”** 휴대폰에 저장된 연락처의 정확한 이름/엄마·어머니 등의 별칭을 찾습니다. 번호가 여러 개면 임의 선택하지 않습니다. 실제 음성으로 “전화할까요?”가 시작된 뒤 **“네”**라고 확인한 경우에만 일반 통화 번호로 연결을 요청합니다. 확인은 30초 후 만료되고 한 번만 사용할 수 있습니다. “취소”는 연결하지 않습니다. 모델이 답변에 적은 전화 명령·번호는 실행하지 않습니다. 긴급전화·USSD·추가 다이얼 코드는 이 기능에서 걸지 않습니다.
- **“이 주변에 병원 있어?”** 위치 권한과 휴대폰 위치를 확인한 뒤 OpenStreetMap의 실제 지도 기록에서 반경 3km를 검색합니다. 이름 있는 병원/의원을 최대 3개 표시하고 가까운 2개를 읽습니다. 약국·화장실·편의점·카페·음식점도 지원합니다. 거리는 좌표 간 대략적인 직선거리이며 경로 거리나 실시간 영업·응급 진료 가능 여부가 아닙니다. 결과가 없으면 없다고 단정하지 않습니다.
- **“지도 열어줘.”** 최근 검색의 지도 링크를 엽니다. 화면 밖에서는 앱 화면이나 알림을 열어 확인합니다. 지도 출처는 © OpenStreetMap contributors / ODbL입니다. 지역별 지도 누락이 있으며 별도 유료 Maps API 키는 필요하지 않습니다.
- **“오늘 할 일을 정리해줘.”** Gemini와 일반 대화를 합니다. 답변은 한국어로 짧게 읽습니다. 앱에 입력한 질문도 같은 기능으로 처리합니다.

## 카메라·서보와 함께 사용

카메라는 기존 ESP/휴대폰 전면·후면, 로컬/Gemini 모드를 유지합니다. 대화 중에는 일반 장면 음성이 겹치지 않도록 멈추고 분석을 계속합니다. 서보 전송을 켜면 신선한 AI 보행 경고에 `OBSTACLE\n`을 보내며 같은 경고는 억제합니다. 원시 YOLO 검출 개수의 깜박임마다 보내지 않습니다. 경고 전송이 켜져 있어야 동작하며, BLE 쓰기 성공은 UNO 수신 ACK가 아닙니다.

## Gemini가 ‘분석 중’에서 실패할 때

**Gemini 설정 → Google 모델 목록 확인 → 모델 선택 → 선택 모델 연결 검사 → 저장 → 장면 설명 재시도** 순서로 확인하세요. 목록 조회 성공은 생성 할당량이 있다는 뜻이 아닙니다. 연결 검사는 짧은 생성 1회로 API 사용량이 발생할 수 있습니다.

- HTTP 400: API 키/요청 기능 문제. 알려진 키 만료·API 비활성 사유는 구분 표시합니다.
- HTTP 401/403: 키·프로젝트 API 권한 문제.
- HTTP 404: 해당 이름의 모델을 사용할 수 없음. Google에서 조회한 목록에서 직접 선택합니다.
- HTTP 429: 요청·할당량 제한. 자동으로 다른 유료 모델을 선택하거나 계속 재요청하지 않습니다.
- HTTP 503/5xx: 서버 혼잡/오류. 카메라는 최소 10초 뒤 최신 사진으로 재시도하며 대화는 다시 질문할 수 있습니다.

사진 요청은 연결 포함 최대 약 20초, 대화 요청은 최대 약 35초를 기준으로 중단합니다. 인터넷 경로 선택에는 별도 대기가 있을 수 있습니다. 단색·불분명한 영상이나 새 위험이 없으면 분석 성공이어도 말하지 않는 것이 정상입니다. 실패와 조용한 성공은 상태 문구로 구분합니다. 카메라의 오래된 답변은 계속 읽지 않습니다.

## 전송·검증 범위

버튼으로 완료한 녹음·질문·최근 대화 최대 4회는 Gemini로 전송됩니다. 취소하거나 전송 버튼을 누르지 않은 녹음은 Gemini로 보내지 않습니다. ElevenLabs 사용 시 답변 문장을 ElevenLabs로 전송합니다. 주변 검색 시 현재 좌표를 Overpass 지도 서버로 전송하고, 지도를 열면 선택 좌표를 지도 서비스에 전달합니다. 연락처 목록 전체는 Gemini로 보내지 않으며 사용자가 발화한 이름과 최근 대화에 포함된 내용은 전송될 수 있습니다. 개인 API 키는 기기에서 암호화해 저장하고 소스/APK에 넣지 않습니다.

단위 검사에는 버튼 두 번의 녹음·전송, 중복 클릭, 60초 보관 후 명시적 전송, 답변·요청 취소 후 새 녹음, 답변 완료 후 마이크 대기, 전화 확인 유지, 늦은 입력 콜백 폐기와 기존 명령·BLE·WAV·모델 오류 처리가 포함됩니다. Android 15에서 실제 AudioRecord의 시작·버튼 완료·취소 후 재시작과 비서 대기 서비스의 Home 이후 유지·중지를 검사합니다. 실제 HM-10·SG90·버튼·이어폰·위치·SIM 통화의 통합 동작과 지도 서버의 실시간 응답은 별도 실기 확인이 필요합니다. 이 변경은 로컬 이미지 분석 속도를 바꾸지 않습니다.
