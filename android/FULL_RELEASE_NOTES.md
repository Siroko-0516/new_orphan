ESP32 카메라 영상 → 휴대폰 YOLO 감지, MiniCPM-V 4.7 1B 장면 설명, HM-10 BLE 알림을 위한 Android 8 이상 ARM64 테스트 앱입니다.

MiniCPM 언어 모델 Q4_K_M과 해당 비전 mmproj가 APK에 함께 들어 있습니다. 모델 파일을 별도로 선택하거나 다운로드할 필요 없이 사진을 준비하고 **기기에서 사진 분석**을 누르면 앱 내부에서 준비·실행합니다. YOLO는 **ESP 영상 + YOLO 시작**으로 실행합니다. 장면 설명은 버튼을 눌러 한 장씩 분석합니다.

- APK는 약 1.8GB이며, 설치 후 첫 AI 준비에 내부 저장 공간 약 1.8GB가 추가로 필요합니다. 설치 과정까지 고려해 넉넉한 저장 공간을 확보하세요. RAM 요구량과 저장 공간은 다릅니다.
- 이전 공개 0.1.0/0.2.0과 서명이 다를 수 있습니다. 서명 충돌로 설치가 안 되면 기존 앱을 삭제한 뒤 설치하세요. 삭제 시 기존 앱의 내부 모델 복사본·데이터가 삭제됩니다.
- 휴대폰을 ESP32-CAM Wi-Fi에 연결하고 `http://192.168.4.1:81/stream`을 사용합니다. 인터넷이 없는 Wi-Fi 연결을 유지하세요.
- 한국어 장면 설명은 실험적이며 언어 혼합이나 부정확한 설명이 있을 수 있습니다. 오프라인 TTS는 휴대폰에 해당 음성이 설치되어 있어야 합니다.
- 빌드·정적 검사·파일 무결성 검사는 실제 휴대폰에서의 속도·RAM·카메라·BLE 동작 검증을 대신하지 않습니다.

소스와 가중치 라이선스·출처는 저장소의 `android/` 및 APK `assets/licenses/`, `assets/local-ai/`에 포함합니다. MiniCPM 가중치는 Apache-2.0, YOLO 관련 AGPL-3.0 등 각 구성 요소의 조건이 적용됩니다.
