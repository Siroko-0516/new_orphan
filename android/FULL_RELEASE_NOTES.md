ESP32 카메라 영상 → 휴대폰 YOLO 감지, 로컬 AI / Gemini 장면 설명 선택, HM-10 BLE 알림을 위한 Android 8 이상 ARM64 테스트 앱입니다.

앱 상단에서 **로컬 AI · 오프라인** 또는 **클라우드 AI · Gemini**를 선택합니다. 기본 선택은 로컬이며, 선택을 다음 실행에도 기억합니다. 모드 선택만으로 사진을 전송하지 않고, 분석 버튼을 눌렀을 때 선택한 쪽으로 한 장을 처리합니다. 실패 시 다른 모드로 자동 전환하지 않습니다.

로컬: MiniCPM 언어 모델 Q4_K_M과 해당 비전 mmproj가 APK에 함께 들어 있습니다. 모델 파일을 별도로 선택하거나 다운로드할 필요 없이 사진을 준비하고 **기기에서 사진 분석**을 누르면 앱 내부에서 준비·실행합니다.

Gemini: **Gemini API 키 · 모델 설정**에서 본인 API 키를 입력한 뒤 **Gemini로 사진 분석**을 누릅니다. 기본 모델은 `gemini-3.1-flash-lite`이고 모델 이름을 변경할 수 있습니다. 선택한 사진이 Google로 전송되며 인터넷·사용 가능한 API 할당량이 필요하고 요금이 발생할 수 있습니다. 개인 키는 Android Keystore로 암호화해 휴대폰에 저장하며 APK에 공유 키를 넣지 않습니다.

YOLO는 **ESP 영상 + YOLO 시작**으로 실행합니다. 장면 설명은 버튼을 눌러 한 장씩 분석합니다. Gemini를 선택하면 로컬 VLM 메모리를 해제하고, 다시 로컬을 선택해 분석할 때 불러옵니다. 분석 중에는 중지를 요청하고 완료된 후 모드를 바꿀 수 있습니다.

- APK는 약 1.8GB이며, 설치 후 첫 AI 준비에 내부 저장 공간 약 1.8GB가 추가로 필요합니다. 설치 과정까지 고려해 넉넉한 저장 공간을 확보하세요. RAM 요구량과 저장 공간은 다릅니다.
- 기존 0.3.0-full 배포판의 서명을 CI에서 재사용합니다. 같은 서명이면 삭제 없이 업데이트할 수 있고 준비된 로컬 모델 복사본도 재사용합니다. 다른 디버그 빌드와 서명 충돌로 설치가 안 되면 기존 앱을 삭제한 뒤 설치해야 하며, 삭제 시 앱 내부 데이터도 삭제됩니다.
- 휴대폰을 ESP32-CAM Wi-Fi에 연결하고 `http://192.168.4.1:81/stream`을 사용합니다. 인터넷이 없는 Wi-Fi 연결을 유지하세요.
- ESP Wi-Fi를 유지하며 Gemini도 쓰려면 모바일 데이터 등 별도 인터넷 연결이 필요합니다. 앱은 카메라를 로컬 Wi-Fi로, Gemini 요청을 인터넷 경로로 연결합니다. 활성 VPN을 우회하도록 설정하지 않습니다. 실제 휴대폰의 동시 연결은 기기에서 확인해야 합니다.
- 로컬 모델의 한국어 설명은 실험적이며 언어 혼합이 있을 수 있습니다. 어느 모드든 설명이 부정확할 수 있습니다. 오프라인 TTS는 휴대폰에 해당 음성이 설치되어 있어야 합니다.
- 빌드·정적 검사·JVM 테스트·파일 무결성 검사와 서버에서의 실제 Gemini 사진 API 요청 성공은 Android 기기의 속도·RAM·동시 네트워크·Keystore·카메라·BLE 실물 검증을 대신하지 않습니다.
