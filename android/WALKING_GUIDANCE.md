# 보행 상황 판단 · 0.8.1

0.7의 짧은 YOLO ‘감지’ 음성은 제거했습니다. 자동 실행은 이전·최신 사진을 계속 확인하면서 AI가 안내 여부를 판단합니다. 같은 보행 상황이면 분석만 이어가고 말하지 않습니다. 새 통로 방해물이나 사진에서 확인되는 악화된 상황만 자연스러운 한국어로 짧게 설명합니다. 사진 한 장 분석과 ESP·휴대폰 카메라·BLE·백그라운드는 유지합니다.

## 흰지팡이 카메라와 반복 억제

흰지팡이를 좌우로 움직일 때 물체가 사라졌다 다시 보이거나 의자 개수가 바뀌어도 바로 새 음성 이벤트로 만들지 않습니다. 같은 계열 물체를 5개 관측 중 3개로 확인하고 12초 동안 관측 상태를 유지합니다. 통로 후보는 아래·중간·위쪽을 모두 포함하되, 화면 중앙이 실제 보행 방향이라고 확정하지 않습니다. 상단의 물체를 실제 머리 높이의 장애물로 단정하지 않습니다.

Gemini에는 직전 검토 사진·최근 사진·최신 사진을 시간 순서로 최대 3장, 총 2MB 이하로 보냅니다. 로컬 AI는 최신 사진과 직전에 실제 안내한 영어 장면 설명을 짧게 비교합니다. 복잡한 한국어 지시문을 따라 쓰던 문제를 실제 모델로 재현해, 짧은 영어 지시와 JSON 문법 제약으로 바꿨습니다. 일반 풍경 설명을 통로 장애물 안내로 읽지 않는 보행 적합성 검사도 적용합니다. AI는 `speak`, `message`, `urgency`를 반환합니다. 같은 상황은 `speak=false`; 같은 물체라도 새롭게 악화된 통로 방해가 분명하면 `urgent`를 사용할 수 있습니다. 모델이 말하겠다고 해도 이미 전달한 의미·잠시 변한 감지 수·표현만 다른 반복 문장은 다시 읽지 않습니다.

‘화면 중앙에 의자 감지’ 같은 좌표 나열을 읽지 않습니다. 예를 들어 사진에서 전방 통로가 확인되면 ‘전방 통로에 의자가 놓여 있는 것 같아요’처럼 설명합니다. 감지 상자의 크기·위치로 2m를 만들어내지 않습니다. **현재 카메라는 실제 2~3m 거리·사용자의 진행 방향·머리 높이를 실측하지 않습니다.** 거리·걸음 수·충돌 예측·안전한 경로를 보장하는 문장은 음성에서 제외합니다. 계단·작은 단차·상단 돌출물 등 모든 위험을 정확히 알아낸다는 보장은 아닙니다.

분석과 음성은 각각 한 번에 하나만 처리합니다. 5초가 넘은 사진의 새 음성은 시작하지 않고, 상황이 달라지면 이미 재생 중인 음성도 취소합니다. 신선한 사진으로 시작한 짧은 안내는 같은 상황에서 문장을 끝낼 시간을 주되 촬영 후 최대 12초 이내로 제한합니다. 오래 걸리는 로컬 결과를 보행 중 뒤늦게 읽지 않습니다. 수동 사진 한 장 분석에는 이 실시간 유효기간을 적용하지 않습니다.

## Gemini와 음성 대체

기본 확인 시작 간격은 2초입니다. 이전 분석이 완료돼야 다음 사진을 확인하므로 2초마다 답변 완료를 보장하지 않습니다. 자동 실행 중 사진이 Google로 반복 전송되며 사용량이 발생합니다. Gemini 3 보행 분석은 빠른 판단용 MINIMAL 설정과 JSON 응답을 사용합니다. 다른 모델에는 지원이 불분명한 Gemini 3 전용 설정을 보내지 않습니다.

Gemini가 실제 안내를 선택하면 기존 여자/남자 ElevenLabs 음성으로 읽습니다. YOLO 이벤트가 ElevenLabs를 중단시키던 경로를 제거했습니다. API 인증·할당량·연결·지연·MP3·재생 오류가 나면 현재 안내를 기본 한국어 음성으로 한 번 대체합니다. 사용자 중지·지난 상황·취소된 요청에는 대체 음성도 내지 않습니다. 음성 생성 대기와 실제 재생 시작을 구분하며, 재생을 시작한 안내만 ‘이미 말한 내용’으로 기억합니다.

## 로컬 이미지 가속과 한국어

기존 언어·비전 모델과 입력 해상도를 유지합니다. 병목인 비전 인코더에 선택형 Vulkan GPU 가속을 추가했습니다. 언어 모델은 CPU에 유지하고, 지원되는 기기의 이미지 연산만 GPU를 사용합니다. ‘이미지 GPU 가속 자동’을 켜면 Android 9 이상에서 사용 가능한 GPU를 확인합니다. 지원하지 않거나 초기화·연산을 완료하지 못하면 CPU로 돌아갑니다. 가속 중 앱이 비정상적으로 끝나면 다음 실행은 보수적으로 CPU를 사용하며 체크를 껐다 켜 다시 시도할 수 있습니다.

최초 GPU 준비는 셰이더·메모리 준비 때문에 오래 걸릴 수 있습니다. 결과에 GPU/CPU와 준비·이미지·생성 시간을 표시합니다. **실제 휴대폰에서 이미지 처리 40초가 몇 초로 줄었는지와 2초 이하 달성은 아직 측정하지 않았습니다.** GPU 라이브러리의 빌드 성공과 실제 기기 성능은 다릅니다. CPU로 돌아간 기기에서 오래 걸린 결과는 실시간 음성으로 읽지 않습니다.

기본 사진 설명 언어는 로컬/Gemini 모두 한국어입니다. 수동 사진 분석에서는 영어를 직접 선택할 수 있습니다. 로컬 한국어 안내는 짧은 영어 설명을 번역하므로 먼저 ‘오프라인 한국어 번역 준비 · 최초 인터넷’을 한 번 누르면 MLKit 번역 모델을 내려받아 기기에서 한국어로 바꿉니다. 번역을 위해 사진 분석을 다시 돌리지 않으며, 사진·번역 문장을 번역 서버에 보내지 않습니다. 모델 준비 전에는 영어를 한국어인 것처럼 읽지 않고 설정 안내를 표시합니다. 번역 모델 다운로드·실제 휴대폰 번역 품질은 별도 확인이 필요합니다.

## 검증 범위

회귀 검사는 좌우 스윙·물체 소실·개수/계열 변동·상단 관측·관측 유지·통로 에피소드·반복 표현·의미 있는 악화·지난 음성·대체 음성 취소·한국어 번역 준비·Gemini 비교 사진/응답 형식을 검사합니다. 실제 ARM64 Vulkan 셰이더·JNI 빌드와 16KB 정렬, CPU만 사용할 때 Vulkan에 의존하지 않는 구성도 확인합니다. API 키를 APK에 포함하지 않으며 개인 Gemini·ElevenLabs 키는 앱 설정에 입력합니다. 공개 APK의 최종 검증 결과는 게시 후 기록합니다.
