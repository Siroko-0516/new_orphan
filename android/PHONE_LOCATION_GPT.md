# 길잡이 0.9.3 · 현재 위치·전화·주변 검색·GPT

위치·전화·지도 명령은 앱이 휴대폰 기능으로 처리합니다. Gemini/GPT의 일반 답변으로 실행 결과를 대신하지 않습니다. 정식 UNO v5와 기존 버튼 신호 `ASSIST`를 그대로 사용하며, 버튼 한 번은 녹음 시작, 다시 한 번은 전송입니다. 답변 중 버튼은 답변을 취소하고 새 녹음을 시작합니다.

## 처음 사용할 때

**공개 0.9.3은 공개 0.9.2와 서명이 달라 기존 앱을 삭제한 후 설치해야 합니다.** 삭제하면 저장한 API 키·설정·준비한 모델 복사본이 초기화됩니다. 개인 키를 다시 입력할 준비를 하고 설치하세요. 정식 UNO v5는 다시 올릴 필요가 없습니다. APK는 1,828,272,025바이트(약 1.83GB)이며 로컬 모델 두 파일을 포함합니다.

앱의 **음성비서 시작**을 누르고 마이크·주변 기기 권한을 허용합니다. 처음 한 번 위치·연락처·전화 권한도 요청합니다. 권한을 거절한 기능은 실행하지 않으며 **위치·연락처·전화 권한 설정**에서 다시 허용할 수 있습니다. 휴대폰 위치 기능도 켭니다. 정상 통화에는 전화 기능과 사용 가능한 SIM·통신망이 필요합니다.

**현재 위치 확인 · AI 서버 없이 조회** 버튼과 텍스트 기기 명령은 AI 키 없이도 사용할 수 있습니다. 음성을 알아듣거나 일반 대화를 생성하려면 선택한 Gemini/OpenAI API 키가 필요합니다. Gemini가 503인 동안에는 위치 버튼이나 텍스트 기기 명령으로 앱 자체 기능을 확인할 수 있습니다.

## 현재 위치

- **“내 위치가 어디야”, “현재 위치 알려줘”, “나 어디야”, “여기가 어딘지 알려줘”**는 휴대폰 위치 조회로 연결합니다.
- GPS·네트워크·기기의 fused 위치 중 최근 값을 사용합니다. 정확한 신호를 못 받았을 때는 최근 2분 이내, 정확도 3km 이내의 대략 위치도 사용할 수 있으며 좌표·추정 정확도·확인 시각을 표시합니다. 오래됐거나 잘못된 좌표를 만들어서 반환하지 않습니다.
- 주소는 Android 지오코더에서 확인합니다. 주소 조회가 안 돼도 확인된 좌표와 지도 링크를 남깁니다. Gemini/GPT가 주소를 추측하지 않습니다.
- **“지도 열어줘”** 또는 **확인한 위치 / 주변 장소 지도 열기**로 지도를 확인합니다. 화면 밖에서는 앱 화면이나 실행 알림을 연 뒤 지도가 열립니다.

위치 권한 없음·휴대폰 위치 꺼짐·신호 대기 실패는 각각 안내합니다. GPS 수신과 주소 서비스 자체의 가용성은 앱이 보장할 수 없습니다. 위치·장소 답변을 일반 AI 대화 기록에 넣지 않습니다. 기존 ElevenLabs 음성을 사용하면 읽을 답변 문장은 해당 TTS 서비스로 전송됩니다.

## 연락처 전화

1. **“엄마에게 전화해줘”, “아빠한테 전화 걸어줘”**라고 말하거나 입력합니다.
2. 앱이 휴대폰 연락처의 이름·별칭을 확인합니다. 같은 이름의 번호가 여러 개면 임의로 고르지 않습니다.
3. **“엄마에게 전화할까요?”**가 실제로 재생된 뒤 버튼을 눌러 **“네”**라고 말하고 다시 눌러 전송합니다. 텍스트로 **네**를 보내도 됩니다.
4. 앱은 Android의 시스템 전화 API에 해당 번호로 발신을 요청합니다. 통화 연결 여부는 실제 전화 앱·SIM·통신망에서 결정합니다.

확인은 한 번만 사용할 수 있고 30초 후 만료됩니다. 취소·음성 재생 전 확인·권한 없음에는 발신하지 않습니다. AI가 답변에 적은 전화 명령이나 번호는 실행하지 않습니다. 전화만 요청하고 대상 이름이 없으면 이름을 알려 달라고 안내합니다. 연락처 목록 전체를 AI에 보내지 않습니다.

## 주변 병원·장소

**“주변에 병원 있냐”, “가까운 의원 찾아줘”, “근처 약국 있어?”**를 실제 지도 검색으로 연결합니다. 기본 지도 서버의 통신·서버 오류에는 예비 서버를 한 번 시도합니다. 전체 지도 요청은 12초로 제한하고 429 한도 오류는 다른 서버로 재시도하지 않습니다.

두 서버가 실패하거나 목록을 못 가져와도 확인한 좌표로 **지도 검색 링크**를 준비합니다. **지도 열어줘** 또는 앱의 지도 버튼으로 휴대폰 지도 검색을 열 수 있습니다. 병원 이름·거리·운영 여부를 AI가 만들어서 말하지 않습니다. 데이터에 결과가 없다는 것은 주변에 병원이 없다는 뜻이 아닙니다.

OpenStreetMap 서버에 좌표와 장소 종류를 전송하고, 지도를 열면 해당 지도 서비스로 검색 위치를 전달합니다. 장소 데이터 출처는 © OpenStreetMap contributors / ODbL입니다.

## GPT 설정

1. **GPT · OpenAI API 키 · 모델 설정**에 본인의 OpenAI API 키를 입력합니다. 키는 이 기기의 Android Keystore로 암호화해 저장하며 Gemini·ElevenLabs 키와 분리합니다.
2. **OpenAI 모델 목록 확인 → 선택 GPT 모델 연결 검사 → 저장**으로 사용 가능한 모델을 확인합니다. 기본 모델은 `gpt-4.1-mini`이며 계정의 가용성·권한·할당량에 따라 달라집니다. 목록 조회 성공과 생성 성공은 별도입니다.
3. 사진·보행 AI는 상단의 **GPT · OpenAI**를 선택합니다. 음성비서는 별도의 **음성비서 AI 선택 → GPT 음성비서**를 선택합니다. 로컬 카메라와 GPT 음성비서를 함께 사용할 수도 있습니다.

GPT 음성은 `gpt-4o-mini-transcribe`로 전사한 뒤 동일한 앱 기기 명령에 연결합니다. 일반 대화만 GPT 답변을 요청합니다. 사진·음성·질문·일반 대화 기록이 OpenAI로 전송되고 API 사용료가 발생합니다. **ChatGPT 구독 사용량과 OpenAI API 결제는 별개입니다.** 키가 없거나 API 잔액·권한이 부족하면 명확히 안내하며 다른 유료 모델로 자동 전환하지 않습니다.

Gemini와 로컬 AI는 유지합니다. 클라우드 음성은 기존 고정 ElevenLabs 여자/남자 목소리를 사용하고 실패하면 기본 한국어 TTS로 대체합니다. **로컬 장면 AI는 기본 TTS만 사용합니다.** 실시간 AI를 중지해도 BLE 연결은 별도 유지합니다.

SHA-256은 `ca00af824ec7e62f175f4da4decedad96f542193cebe0aae8054e9d0d5260c74`입니다.

전화·현재 위치 명령의 앱 분기, 발신 전 음성 확인과 한 번만 발신, 권한 거절, 지도 서버 오류 대체 링크, OpenAI 사진·음성 HTTP 형식과 취소·오류·키 보호를 단위 검사합니다. 단위 검사의 전화 API는 모의 처리합니다.

**추가 컴퓨터 검사에서는 실제 Android 15의 연락처·Telecom·Google 전화 화면을 사용했습니다.** 테스트 연락처 조회 → 앱의 발신 코드 → 시스템 통화 등록 → 발신 화면을 확인했습니다. 전화 API를 모의 처리하지 않은 검사이며 [실행 기록](https://github.com/Siroko-0516/new_orphan/actions/runs/41671059104) · [발신 화면](https://github.com/Siroko-0516/new_orphan/releases/download/android-v0.9.3-full/phone-system-screen.png) · [결과 JSON](https://github.com/Siroko-0516/new_orphan/releases/download/android-v0.9.3-full/phone-system-check.json)을 공개합니다. 가상 모뎀의 통화 상태를 검사했으며 실제 통신망이나 상대편 연결, 가상 상대 전화기의 수신은 확인하지 못했습니다. 이 실행 검사는 음성인식과 발신 확인 음성의 실제 재생을 포함하지 않습니다.
