# 변화 안내·로컬 가속·ElevenLabs · 0.7.0

자동 실행은 시작할 때 한 번 설명한 뒤, 확인된 큰 장면 변화에만 AI 설명을 다시 요청합니다. 최소 분석 간격은 변화가 있을 때의 시작 간격이며, 주기적으로 같은 사진을 전송하지 않습니다. 노출 변화·일시적인 흔들림은 걸러내고, 큰 변화는 3프레임/400ms 이상 확인합니다. 확인된 새 장애물은 YOLO 관측으로 짧게 안내하며 긴 VLM 추론을 기다리지 않습니다. 한 장면에 이미 있던 여러 물체를 차례로 모두 읽지 않도록 음성 이벤트를 묶습니다. 기존 BLE 이벤트는 유지합니다.

변화 감지는 16×12 공간 색상 샘플과 감지 상자에 기반한 휴리스틱입니다. 실제 물체의 신원·거리·이동·충돌 가능성을 측정하지 않습니다. 작은 장애물·계단은 YOLO의 지원 클래스나 해상도 한계로 놓칠 수 있습니다. 단색·매우 어둡거나 밝은 영상은 AI에 보내지 않고 ‘확인하기 어렵다’는 입력 안내를 표시합니다. 모델 지시문도 보이는 물체에 한정하고 지팡이 감지 성능에 대한 근거 없는 문장을 차단합니다. 모든 오인식·환각을 제거했다는 뜻은 아닙니다.

분석 중 화면에 부분 설명과 처리 단계를 표시합니다. 장면이 달라졌거나 새 장애물이 나타난 경우 이전 사진의 늦은 설명은 음성으로 읽지 않습니다. 계산 중 새 장애물 감지·짧은 안내·BLE는 별도로 이어집니다.

## 로컬 속도

기존 MiniCPM-V 4.7 1B 언어 Q4_K_M·비전 F16 모델과 YOLO 입력·감지 임계값을 유지합니다. 저해상도 이미지로 몰래 대체하거나 YOLO 안내를 VLM 결과로 표시하지 않습니다.

- 기본 ARMv8, dot-product, FP16, i8mm 네 가지 CPU 백엔드를 동봉하고 지원되는 경로를 런타임에 선택합니다. 기기의 지원 여부는 네이티브 기능 검사에서 확인합니다.
- KleidiAI v1.24.0을 사용하고 아카이브 SHA-256을 고정합니다. 원본 라이선스를 APK에 동봉합니다.
- 첫 실제 사진 전에 수행하던 비전 모델의 더미 이미지 예열을 생략합니다.
- 답변 상한을 192 → 96 토큰으로 줄이고 두 짧은 문장이 완성되면 종료합니다. 보조 YOLO 입력은 신뢰도·면적 기준을 통과한 최대 3개 관측으로 줄입니다.
- 느린 장면 설명 작업은 백그라운드 우선순위로 실행해 카메라·YOLO 처리를 우선합니다.
- 모델 준비·이미지 처리·문장 생성 시간을 따로 표시하고 CPU 기능을 오류 기록에 남깁니다.

사용자가 보고한 84초는 기존 APK의 실제 휴대폰 측정입니다. 새 APK의 휴대폰 추론 시간을 아직 측정하지 않았으며, **사진 전체를 이해해 문장을 생성하는 로컬 VLM이 매번 1~2초에 완료된다고 보장하지 않습니다.** 짧은 YOLO 안내 시간과 전체 VLM 추론 시간은 구분합니다. 실제 변화 감지·카메라·TTS 지연도 휴대폰 성능·주변 조건에 따라 달라집니다.

## Gemini 음성

Gemini의 AI 장면 설명은 ElevenLabs, 로컬 모드의 AI 설명은 휴대폰 오프라인 음성을 사용합니다. 빠른 YOLO 새 물체 안내는 두 모드 모두 네트워크 요청을 기다리지 않는 휴대폰 오프라인 음성입니다. **ElevenLabs API 키 · 고정 음성 설정**에서 개인 키를 입력합니다. Gemini 키와 별개의 Android Keystore 키로 암호화합니다. 공유 API 키는 소스·APK·서비스 Intent에 넣지 않습니다.

기존 웹 음성 모델 `eleven_multilingual_v2`와 기본 voice settings를 유지하며 제공한 두 Voice ID만 선택합니다.

- 여자 기본값: `lhTvHflPVOqgSWyuWQry`
- 남자: `LS3HmRGCXV8wxCAhUbTt`

ElevenLabs에는 설명 텍스트만 전송합니다. 별도 인터넷·사용량이 필요합니다. 요청·오디오 크기·시간을 제한하고 중지/모드 전환 시 연결·재생을 취소합니다. 임시 MP3는 재생 뒤 삭제합니다. 오류는 음성 상태에 표시하며 임의의 다른 음성으로 전환하지 않습니다. 키나 공급자 응답 원문을 오류에 출력하지 않습니다.
