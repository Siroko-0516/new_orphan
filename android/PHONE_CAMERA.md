# 휴대폰 카메라 · 0.6.0

기존 ESP32-CAM, YOLO11n, MiniCPM 로컬 / Gemini, 기본 TTS, HM-10 BLE와 자동 분석에 휴대폰 후면·전면 입력을 추가했습니다. 기본 입력은 기존 ESP이며 마지막 선택을 저장합니다.

1. **영상 입력 선택 → 휴대폰 후면 카메라** 또는 **휴대폰 전면 카메라**를 고릅니다.
2. **영상 + YOLO 시작**으로 감지 화면부터 확인하거나, AI를 선택하고 **실시간 AI + 백그라운드 시작**을 누릅니다.
3. Android 카메라 권한을 허용합니다. 자동 실행은 앱이 보이는 상태에서 시작해야 합니다.
4. 앱 또는 실행 알림에서 중지합니다. 입력을 전환하려면 먼저 중지합니다.

휴대폰 입력은 ESP 주소와 Wi-Fi를 사용하지 않습니다. 로컬 AI는 준비 후 인터넷 없이 실행합니다. Gemini는 기존처럼 개인 키·인터넷이 필요하며 반복 분석 중 사진을 Google로 전송합니다. 기본 사진 선택·카메라 촬영·ESP 사진 받기도 유지합니다.

자동 실행은 Android 카메라 포그라운드 서비스로 처리합니다. YOLO 전용 영상은 앱 화면을 벗어나면 중지합니다. 휴대폰의 카메라 차단 설정·다른 카메라 앱·제조사 전원 관리 정책에 따라 카메라 접근이 제한될 수 있으며 오류는 앱에 표시합니다. 카메라·서비스를 정지하면 촬영 자원을 닫습니다.

## 구현과 검증

Camera2의 YUV_420_888 최신 이미지에 대해 한 번에 한 프레임만 처리합니다. 기본 640×480 근처의 지원 해상도를 선택하고 최대 변 길이 1280으로 제한합니다. 패딩·픽셀 스트라이드·평면 위치·crop을 반영하고, 센서 방향과 화면 회전을 적용하며 전면은 좌우 반전합니다. 같은 비트맵으로 YOLO·화면·JPEG를 생성해 설명 입력과 감지 상자 좌표를 맞춥니다. YOLO 입력 416, 점수/NMS 임계값과 클래스는 유지합니다.

단위 검사는 YUV 검정/흰색·색상·패딩·인터리브·crop·절단 데이터, 회전, 입력 설정 Intent 왕복, ESP 주소 제한과 캡처 크기 제한을 검사합니다. Android 15 에뮬레이터 계측 검사는 후면·전면 Camera2 → 실제 YOLO → 일치하는 JPEG 치수, 앱 입력 선택 → 자동 서비스, 홈 화면·화면 꺼짐 동안 새 프레임, 서비스 중지 뒤 카메라 재개방을 검사합니다.

CI의 `cameraSmokeOnly=true`는 x86_64 에뮬레이터 전용이며 로컬 AI 네이티브와 GGUF를 포함하지 않습니다. 이 검사에서는 API를 호출하지 않고 로컬 모델 미준비로 장면 설명이 일시 중지된 상태에서 영상·YOLO·백그라운드 처리를 확인합니다. 사용자 다운로드는 별도의 ARM64 전체 모델 내장 APK이며, 에뮬레이터 검사와 실제 GGUF 네이티브 회귀 검사·전체 빌드·단위 검사·lint가 성공해야 게시합니다. 실제 휴대폰에서의 장시간 실행·카메라 화질·전체 AI 속도와 BLE 보드 수신은 별도 확인이 필요합니다.

검사 결과와 게시 파일 검증은 빌드 완료 후 이 문서에 기록합니다.
