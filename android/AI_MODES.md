# 로컬 AI / Gemini 선택 · 0.4.0

앱 상단의 두 선택지로 사진 장면 설명 방식을 바꿉니다. YOLO 감지와 HM-10 BLE 알림은 선택한 설명 모델과 별도로 휴대폰에서 실행됩니다.

| 선택 | 사진 분석 위치 | 필요한 준비 |
| --- | --- | --- |
| 로컬 AI · 오프라인 | 휴대폰의 MiniCPM-V 4.7 1B | full APK에 모델 포함, 인터넷·API 키 불필요 |
| 클라우드 AI · Gemini | Google Gemini API | 인터넷, 본인의 API 키와 사용 가능한 할당량 |

처음에는 로컬이 선택돼 있고, 이후 선택을 다음 앱 실행에도 기억합니다. 모드 선택이나 API 키 저장만으로 사진을 전송하지 않습니다. 사진을 준비한 뒤 선택한 모드의 분석 버튼을 눌러 한 장씩 처리합니다. 실패하면 오류를 표시하고 자동으로 다른 모드를 실행하지 않습니다.

## Gemini 사용

1. 앱의 **Gemini API 키 · 모델 설정**을 엽니다.
2. 본인 API 키를 입력해 저장합니다. 키가 없다면 [Google AI Studio](https://aistudio.google.com/)에서 키와 API 사용 가능 여부를 확인합니다. 키를 채팅이나 GitHub에 보내지 말고 앱 입력칸에 직접 입력하세요.
3. **클라우드 AI · Gemini**를 선택하고 사진 선택 또는 ESP 영상으로 사진을 준비합니다.
4. **Gemini로 사진 분석**을 누릅니다. 사진·질문과 활성화된 YOLO 보조 관측이 Google로 전송됩니다. 인터넷 데이터와 모델 사용 요금이 발생할 수 있습니다.

기본 모델은 기존 웹 앱과 같은 `gemini-3.1-flash-lite`입니다. 설정에서 모델 이름을 바꿀 수 있으나 해당 키의 모델 접근 권한·할당량이 필요하고, 모델마다 가격과 응답 시간이 다릅니다. 키 교체는 새 키 입력 후 저장, 삭제는 **저장된 키 삭제**를 사용합니다. 기존 키를 유지하면서 모델 이름만 바꾸려면 키 입력칸을 비워둡니다.

기본 질문을 쓰던 상태에서 Gemini를 고르면 한국어 질문을, 로컬을 고르면 영어 질문을 기본으로 제공합니다. 사용자가 직접 수정한 질문은 모드 전환 시 유지합니다. 언어 선택에서 직접 바꿀 수도 있습니다. 로컬 모델의 한국어 혼합 현상을 이 선택 UI가 해결하지는 않습니다.

## ESP Wi-Fi와 인터넷을 함께 사용

ESP32-CAM 자체 Wi-Fi에는 보통 인터넷이 없습니다. 휴대폰은 ESP Wi-Fi 연결을 유지하고, Gemini에는 모바일 데이터 등 별도 인터넷 연결이 필요합니다.

카메라 요청은 기존처럼 ESP로 가는 Wi-Fi 경로에 연결합니다. Gemini는 기본 인터넷 경로를 먼저 사용하고, 필요할 경우 모바일 데이터 인터넷 경로를 요청합니다. 앱은 모바일 데이터를 강제로 켜지 않으며 연결을 구하지 못하면 안내 메시지를 표시합니다. 활성 VPN이 있으면 해당 VPN 경로를 사용하고 우회하지 않습니다. 이 동시 연결은 실제 휴대폰·통신사·VPN 설정에서 확인해야 합니다.

## 전환·메모리·중지

Gemini로 전환하면 로컬 VLM 메모리를 해제합니다. 내장 모델의 저장 파일은 남아 있으므로 로컬로 돌아와 분석하면 다시 불러옵니다. Gemini 모드는 로컬 모델을 준비하지 않아도 분석할 수 있습니다. 단, 이 full APK에는 로컬 모델도 계속 들어 있어 다운로드 크기는 약 1.8GB입니다.

분석 중에는 모드 변경을 잠시 막습니다. **중지 요청** 후 현재 작업이 중지되면 다른 모드를 고를 수 있습니다. Gemini의 연결 대기·업로드·응답 읽기는 중지 신호를 확인하며 연결을 닫습니다. 이미 Google에 도달한 요청의 서버 처리나 비용까지 취소한다고 보장하지는 않습니다. 로컬 모델의 긴 네이티브 처리 중에는 즉시 중지되지 않을 수 있습니다.

## 키 저장과 요청 범위

APK에 공동 API 키나 개발 환경의 API 키를 넣지 않습니다. 개인 키는 Android Keystore의 AES-GCM 키로 암호화한 후 앱 내부 SharedPreferences에 보관하며, 평문 저장으로 대체하지 않습니다. 기본 앱 백업도 꺼져 있습니다. 이 설계가 루팅·변조된 기기까지 보호한다는 의미는 아닙니다.

Google 공식 HTTPS 주소에만 요청하고 API 키는 URL이나 질문 본문 대신 `x-goog-api-key` 헤더에 넣습니다. 리다이렉트를 따라가지 않으며 HTTP 오류 본문을 화면에 그대로 출력하지 않습니다. 사진은 앱에서 최대 768px로 준비하고, 클라이언트는 JPEG 2MB 및 응답 1MB 제한을 적용합니다. 자동 재시도는 하지 않습니다.

## 검증 범위

Android ARM64 모델 내장 빌드·Lint와 JVM 테스트, 로컬 HTTP POST 전송, 요청 중지·오류·응답 크기 제한, AES-GCM 변조 방지 등을 검사했습니다. 실제 Gemini API에 공개 풍경 시험 사진을 요청해 HTTP 200과 한국어 설명을 받았고, 앱 클라이언트의 요청 생성기와 응답 파서로 이를 확인했습니다.

실제 휴대폰에서의 Android Keystore 저장, ESP Wi-Fi와 모바일 데이터 동시 연결, 화면 전환, 모델 메모리와 속도, BLE·오프라인 음성은 별도 실기기 확인이 필요합니다.
