# 길잡이 · 프로젝트 소개와 문의 사이트

포스터 QR을 통해 프로젝트 소개·연결 구조·사용 방법·앱 다운로드·FAQ와 문의 창구를 확인하는 별도 사이트입니다.

1.0.1은 한국어 UI 글꼴과 구성도 글꼴을 자체 포함합니다. 한국어 글꼴이 없는 환경에서도 사이트 본문과 구성도가 표시되는지 브라우저에서 확인합니다. 글꼴의 SIL Open Font License와 출처도 포함합니다.

- `giljabi-inquiry-site.zip`: Cloudflare Pages 직접 업로드 파일.
- `giljabi-poster-qr.png` / `.svg`: 현재 공개 GitHub 프로젝트 안내 페이지로 연결하는 인쇄용 QR.
- `Cloudflare-Pages-upload.txt`: 배포 방법과 QR 사용 안내.
- `checks.json`: 업로드 ZIP 크기와 SHA-256.

공개 안내 주소: https://github.com/Siroko-0516/new_orphan/blob/main/inquiry-site/README.md

Cloudflare Workers & Pages에서 **Pages → 직접 업로드**로 ZIP을 배포하면 실제 HTTPS 주소가 생성됩니다. 배포된 사이트 아래의 포스터 도구에서 그 주소를 연결하는 QR을 새로 저장할 수 있습니다. 현재 환경에는 Cloudflare 계정 인증이 없어 Cloudflare 공개 배포를 완료했다고 표시하지 않습니다.

문의는 GitHub 작성 화면으로 연결하며 로그인 후 최종 제출해야 등록됩니다. 내용은 공개됩니다. 이 사이트에 별도의 문의 저장 서버나 이메일 전송 기능이 있는 것처럼 표시하지 않습니다.
