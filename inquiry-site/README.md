# 길잡이 · 프로젝트 소개와 문의

**흰지팡이에 더한 시선.** 카메라와 AI를 흰지팡이에 연결해 주변 정보를 음성과 모터 동작으로 전달하는 보행 보조 프로젝트입니다.

> 포스터 QR을 통해 방문하셨나요? 이 페이지에서 프로젝트 소개, 사용 방법과 문의 창구를 확인할 수 있습니다.

[**프로젝트 문의 남기기 ↗**](https://github.com/Siroko-0516/new_orphan/issues/new?template=project-inquiry.md) · [기존 문의 보기](https://github.com/Siroko-0516/new_orphan/issues) · [Android 앱 다운로드](https://github.com/Siroko-0516/new_orphan/releases/download/android-v0.9.4-full/giljabi-0.9.4-full-debug.apk)

문의는 GitHub 로그인 후 작성하며 게시 내용은 공개됩니다. 개인정보나 API 키를 포함하지 마세요. 문의 화면에서 최종 제출해야 등록됩니다.

## 왜 만들었나요?

흰지팡이의 접촉 정보에 주변 장면의 정보를 더하고자 시작했습니다. 사용자가 화면을 확인하지 않아도 필요한 정보를 듣고, 물리 버튼으로 음성비서를 사용할 수 있도록 개발했습니다.

## 어떤 기능이 있나요?

- **주변 상황 안내:** 카메라 장면을 분석하고, 변화에 따라 안내하며 비슷한 상황의 반복 안내를 줄입니다.
- **모터 알림:** 앱이 BLE로 신호를 보내면 Arduino UNO에 연결한 SG90 서보모터가 움직입니다.
- **버튼 음성비서:** 버튼 한 번으로 녹음을 시작하고 말을 마친 뒤 다시 눌러 전송합니다. 답변 중에도 버튼으로 말을 중단하고 새 녹음을 시작합니다.
- **위치·주변 병원·전화:** 주소와 검색한 병원 이름·대략적인 직선거리를 음성으로 안내합니다. 전화는 연락처에서 대상을 찾고 확인 질문에 명확하게 긍정해야 발신을 요청합니다.

## 어떻게 연결하나요?

```text
ESP32-CAM → 휴대폰 AI 분석 → 무선이어폰 음성 안내
                         └→ BLE → Arduino UNO → 서보모터 알림

물리 버튼 → Arduino UNO → HM-10 BLE → 휴대폰 음성비서
```

Gemini·GPT와 로컬 장면 AI를 선택할 수 있습니다. 로컬 장면 AI는 휴대폰 기본 한국어 TTS만 사용합니다. Gemini·GPT 음성비서는 ElevenLabs를 사용할 수 있고 오류가 나면 기본 TTS로 대체합니다.

## 앱 사용 방법

1. 카메라·BLE 장치를 연결하고 마이크·위치·연락처·통화 권한, 선택한 AI 키와 한국어 음성을 준비합니다.
2. 음성비서를 시작한 뒤 물리 버튼을 눌러 녹음을 시작합니다.
3. 질문을 말하고 버튼을 다시 눌러 전송하면 답변을 들을 수 있습니다.
4. “전화해줘”에는 누구에게 전화할지 묻습니다. 실제 대상 이름을 읽는 확인 질문이 끝난 뒤 “네”라고 해야 발신합니다. “아니요”에는 발신하지 않습니다.

[자세한 앱 사용 설명](../android/VOICE_FIRST_ASSISTANT.md)

**앱 0.9.4-full은 약 1.83GB입니다.** 공개 0.9.3과 서명이 달라 기존 앱을 삭제한 뒤 설치해야 합니다. 삭제하면 API 키·설정·준비한 모델이 초기화됩니다.

## 자주 묻는 질문

**인터넷 없이 사용할 수 있나요?**  
로컬 장면 AI는 모델을 준비한 뒤 기기에서 분석합니다. Gemini·GPT, 음성 질문 전송과 주소·주변 병원 조회에는 인터넷이 필요합니다.

**포스터의 QR 페이지가 카메라나 마이크를 사용하나요?**  
프로젝트 소개와 문의용 사이트는 카메라·마이크·위치 권한을 요청하지 않습니다. 기기 기능은 별도 Android 앱에서 사용합니다.

**정확한 거리와 안전한 경로를 보장하나요?**  
개발 중인 보행 보조 프로젝트로 모든 장애물 발견이나 정확한 거리·안전한 경로를 보장하지 않습니다. 병원 안내의 거리는 지도 기록을 기준으로 한 대략적인 직선거리입니다.

**어디까지 검사했나요?**  
Android 0.9.4 자동 검사 332개와 Android 15 가상 기기의 GPS 위치 갱신·통화 등록·전화 화면 실행 검사를 통과했습니다. 실제 GPS 수신·병원 서버 응답·상대방 통화 연결·이어폰 음성 재생은 별도 실기 확인이 필요합니다. [추가 검사 기록](../android/VOICE_FIRST_SYSTEM_VALIDATION.json).

## 포스터용 사이트 파일과 QR

별도 디자인 사이트의 [Cloudflare 업로드 ZIP과 QR 다운로드](https://github.com/Siroko-0516/new_orphan/releases/tag/inquiry-v1.0.1)를 제공합니다. 공개 Cloudflare 주소는 계정에서 배포를 완료하면 발급됩니다.

같이 제공하는 QR은 **현재 공개된 이 GitHub 안내 페이지**로 연결됩니다. 별도 사이트를 Cloudflare에 배포하면 사이트 아래에서 **그 사이트 주소의 QR**을 저장할 수 있습니다.

포스터 문구: **“프로젝트 소개 및 자세한 문의는 QR 코드를 통해 확인해주세요.”**

업로드 방법은 [UPLOAD.txt](UPLOAD.txt)를 확인하세요. 정적 사이트여서 API 키나 서버 설정이 필요하지 않습니다.

한국어 UI 글꼴을 사이트에 포함하여 외부 폰트 서버에 연결하지 않습니다. Noto Sans CJK 기반 글꼴의 출처·변형과 SIL Open Font License는 [글꼴 안내](assets/fonts/provenance.json)와 [라이선스](assets/fonts/LICENSE.txt)에서 확인할 수 있습니다.
