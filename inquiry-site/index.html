01 / ABOUT THE PROJECT

한 걸음에 필요한
정보를 더합니다.

흰지팡이의 접촉 정보에 주변 장면의 정보를 더하고자 시작했습니다. 휴대폰이 영상을 분석하고, 사용자는 음성과 물리 알림으로 필요한 정보를 확인합니다.

01

주변 상황 안내

카메라 영상에서 주변 상황과 위험 요소를 분석합니다. 이전 상황과 비교하고 비슷한 안내가 반복되지 않도록 조절합니다.

카메라 · 장면 분석
02

손에 닿는 알림

앱이 알림 신호를 보내면 BLE로 연결한 Arduino UNO의 서보모터가 움직입니다. 보드의 물리 버튼은 음성비서를 호출합니다.

HM-10 BLE · SG90 서보
03

대화로 정보 확인

현재 위치와 주변 병원을 물어보고, 연락처에 저장한 사람에게 전화를 요청할 수 있습니다. 발신 전에는 대상과 동의를 다시 확인합니다.

03 / QUESTIONS

궁금한 점을
먼저 확인해보세요.

설치와 사용, 프로젝트에 관한
질문을 모았습니다.

이 사이트에서 카메라나 마이크를 사용하나요?+

이 페이지는 프로젝트 소개와 문의를 위한 사이트입니다. 카메라·마이크·위치 권한을 요청하지 않습니다. 보행 분석과 음성비서 기능은 별도의 길잡이 앱에서 사용합니다.

인터넷 없이 사용할 수 있나요?+

로컬 장면 AI는 모델을 준비한 뒤 기기에서 분석하고 휴대폰 기본 한국어 TTS를 사용합니다. Gemini·GPT, 음성 질문 전송, 주소·주변 병원 검색에는 인터넷이 필요합니다. Gemini·GPT 음성비서는 ElevenLabs를 사용할 수 있고 실패하면 기본 TTS로 대체합니다.

전화해달라고 하면 바로 발신하나요?+

먼저 누구에게 전화할지 묻고 연락처에서 대상을 찾습니다. “○○에게 전화할까요?”라는 확인 질문이 끝난 뒤 명확하게 긍정해야 발신을 요청합니다. 부정하거나 답이 불분명하면 발신하지 않습니다. 실제 통화 연결에는 휴대폰 권한·SIM·통신망이 필요합니다.

장애물 거리나 안전한 경로를 보장하나요?+

길잡이는 개발 중인 보행 보조 프로젝트입니다. 모든 장애물 발견, 정확한 거리 측정, 안전한 경로를 보장하지 않습니다. 병원 안내의 거리는 검색된 위치를 기준으로 한 대략적인 직선거리입니다.

어디까지 검증했나요?+

Android 0.9.4의 자동 검사 332개와 Android 15 가상 기기의 위치 갱신·통화 등록·전화 화면 실행 검사를 통과했습니다. 실제 휴대폰의 GPS 수신, 병원 서버 응답, 상대방 통화 연결과 이어폰 음성 재생은 별도 실기 확인이 필요합니다.
