# HM-10 수신 예제

이 스케치는 **Arduino UNO / 구형 Nano(ATmega328P)** 기준입니다. 다른 보드는 해당 보드의 UART·핀 설정에 맞게 바꿔야 합니다. ESP32-CAM 카메라 펌웨어와는 별도로 아두이노에 업로드합니다.

| 연결 | 대상 |
| --- | --- |
| HM-10 TX | Arduino D10 (SoftwareSerial RX) |
| Arduino D11 (SoftwareSerial TX) | **3.3V 레벨 변환 또는 적절한 분압**을 거쳐 HM-10 RX |
| HM-10 GND | Arduino GND |
| HM-10 VCC | 사용 중인 모듈/캐리어 보드의 정격 전압 |

HM-10 자체는 3.3V 계열이며 캐리어에 따라 VCC 허용 범위가 다릅니다. 5V 허용 전원 입력이 있는 보드도 UART RX가 5V 내성이라는 뜻은 아닙니다. 전원을 끈 상태에서 배선하고 모듈 사양을 확인하세요. 기본 UART 속도는 이 예제에서 9600이며 모듈 설정과 맞춰야 합니다.

1. 스케치를 업로드하고 시리얼 모니터를 **115200 baud**로 엽니다.
2. 앱에서 주변 기기 권한을 허용한 뒤 BLE 검색 → 해당 HM-10 선택 → 연결합니다. 휴대폰 시스템의 페어링이 필수는 아닙니다.
3. **아두이노 TEST 신호 보내기**를 누르면 `TEST\n`을 씁니다. 아두이노에는 `Received: TEST`가 출력되고 내장 LED가 0.2초 켜져야 합니다.
4. ESP 실시간 감지를 시작하고 앱의 **새 물체 감지 시 아두이노 신호 전송**을 켜면 `OBSTACLE\n`을 씁니다. 수신 시 LED가 0.7초 켜지고 로그를 남깁니다.

앱 기본 GATT 서비스는 `0000ffe0-0000-1000-8000-00805f9b34fb`, 쓰기 characteristic은 `0000ffe1-0000-1000-8000-00805f9b34fb`입니다. HM-10 호환 제품이라도 UUID가 다르면 앱의 BLE UUID 설정에서 실제 값을 입력해야 합니다. HC-05/HC-06의 Bluetooth Classic SPP는 이 BLE 연결 방식으로 사용할 수 없습니다.

`BLE 쓰기 완료`는 앱의 GATT 쓰기 콜백입니다. 아두이노가 명령을 받았다는 종단 간 확인은 아니므로 위 LED와 USB 시리얼 로그로 확인하세요. 앱은 연결 종료 시 대기 명령을 버리고 자동 재전송하지 않습니다. 모터·부저·진동 액추에이터 동작은 이 예제에 포함하지 않았습니다.
