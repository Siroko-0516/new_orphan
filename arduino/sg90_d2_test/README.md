# SG90 D2 서보 단독 시험

이 코드는 BLE·AI 없이 60→120→90도를 2초씩 유지하며 반복합니다. 먼저 지팡이 기구물과 서보 혼을 분리해 자유롭게 움직일 수 있는 상태에서 시험하세요.

- 주황 신호선 → UNO D2.
- 빨강 → 안정된 외부 5V 전원 +. SG90 하나에 5V·2A급을 권장합니다.
- 갈색 → 외부 전원 −와 UNO GND 공통 연결.
- UNO는 USB로 전원 공급합니다. 서보 외부 전원 +를 USB로 켠 UNO의 5V 핀에 함께 연결하지 않습니다.

Arduino Uno 보드를 선택해 업로드합니다. **업로드할 때 D0·D1의 HM-10 통신선을 분리**하세요. Servo 라이브러리가 필요합니다. 이 시험 중에는 앱의 TEST·버튼 통신을 처리하지 않습니다. 시험을 마치면 기존 `hm10_sg90_button` v3 전체 코드를 다시 업로드하세요.

L LED는 2초 간격으로 상태가 바뀝니다. LED만 바뀌고 서보가 움직이지 않으면 전원 전압·전류 용량, 공통 GND, D2 신호선 접촉, 서보 자체를 확인해야 합니다. 단독 시험 성공은 BLE·AI 통합 동작을 검증한 것은 아닙니다.
