# HM-10 UART 115200 확인용 · v4 큰 왕복 동작

이 파일은 v4 전체 코드의 UNO UART 속도 한 줄만 9600에서 115200으로 바꾼 확인용입니다. 모듈의 실제 UART 설정이 115200일 때를 시험합니다. BLE 연결 성공과 UNO↔HM-10 UART 속도 일치는 별도입니다.

서보 D2, 버튼 D3, HM-10 TXD→UNO D0(RX), UNO D1(TX)→분압→HM-10 RXD를 사용합니다. GND는 공통 연결합니다. 버튼 V는 3.3V, 서보 전원은 안정된 외부 5V입니다. 경고는 45↔135도 3회 후 90도 복귀입니다.

1. 전원을 끄고 D0·D1 통신선을 분리합니다.
2. Arduino Uno를 선택해 hm10_115200_test.ino 전체 코드를 업로드합니다.
3. 통신선을 다시 연결하고 버튼을 놓은 상태로 전원을 켭니다. PC 시리얼 모니터는 닫습니다.
4. 앱의 AI·음성비서를 중지하고 BLE만 연결한 뒤 TEST를 보냅니다.

앱 TEST에 L LED와 서보가 반응하면 115200 설정에서 UART 통신이 된 것입니다. 앱의 BLE 속도 설정을 바꾸는 절차는 아닙니다. USB로 직접 TEST를 보낼 때에도 시리얼 모니터를 115200 baud·새줄(Newline)로 맞춥니다.

이 시험으로 원인이 확정된 것은 아닙니다. 반응이 없으면 원래 v4(9600)로 돌아갈 수 있습니다. HM-10에 AT 명령을 보내거나 설정을 영구 변경하지 않습니다. 추가 확인에는 실제 수신 데이터나 모듈 모델·전원 정보가 필요합니다.

## 속도를 바꿔도 반응이 없을 때

[수신 기록 점검 v1](../hm10_uart_diagnostic/README.md)은 UNO에 도착한 실제 바이트를 PC 시리얼 모니터에 표시합니다. 점검 중에는 HM-10 TXD→UNO D0만 연결하고 HM-10 RXD를 분리합니다. UART와 모니터는 모두 9600으로 맞춥니다. 이 임시 코드에서는 물리 버튼이 서보를 직접 시험하며, 로그를 출력하므로 일반 v4의 양방향 배선 상태로 사용하지 않습니다.
