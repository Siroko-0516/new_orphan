# 길잡이 UNO · HM-10 · SG90 · 버튼

UNO R3 / ATmega328P용입니다. ESP32-CAM이 아닌 **UNO에 업로드**합니다. Arduino IDE에서 `hm10_sg90_button.ino`를 열고 Arduino UNO 보드를 선택합니다. Servo 라이브러리가 없으면 라이브러리 관리자에서 Arduino의 Servo를 설치합니다.

**v4는 사용자의 배선에 맞춰 서보 D2, 버튼 D3, HM-10 하드웨어 통신 D0·D1을 사용합니다.** S/V/G 3핀 버튼 모듈의 V/+ → UNO 3.3V, G/− → GND, S → D3로 연결합니다. 전원 켜기·리셋·업로드 후 재시작 시에는 버튼에서 손을 떼세요. 약 0.2초 후의 신호를 놓인 상태로 기억해 HIGH/LOW 두 종류 모듈을 모두 처리하며, 시작·버튼 놓기·길게 누르기로 반복 호출하지 않습니다. 모듈의 내장 저항을 사용하므로 기본 코드는 `INPUT`입니다. 맨몸 2핀 버튼이면 코드의 `BUTTON_MODULE`을 `false`로 바꾸면 내부 풀업을 사용합니다.

**블루투스 배선은 교차 연결합니다: HM-10 TX → UNO D0(RX), UNO D1(TX) → 분압 → HM-10 RX.** UNO의 `RX0/TX1` 표시는 UNO 기준입니다. HM-10의 RX를 UNO RX에 같은 이름끼리 연결하지 않습니다. D0·D1은 USB와 공유하므로 **업로드 전 D0·D1의 블루투스 통신선을 빼고, 업로드 완료 후 다시 연결하세요.** 실행할 때 시리얼 모니터는 닫습니다. 코드에서 이 통신 포트에 디버그 문구를 출력하지 않습니다. 앱 설정은 그대로 사용할 수 있습니다.

| 연결 | 대상 |
| --- | --- |
| HM-10 TX | UNO D0 (RX) |
| UNO D1 (TX) | 1kΩ → 접점 → HM-10 RX; 접점에서 2kΩ → GND (5V→3.3V 분압) |
| HM-10 GND | UNO GND |
| HM-10 VCC | 해당 모듈/캐리어의 정격 전압 (3.3V/5V 표기 확인) |
| SG90 주황 신호 | UNO D2 |
| SG90 빨강 전원 | 외부 정전압 5V 전원 + |
| SG90 갈색 GND | 외부 전원 − 및 UNO GND 공통 |
| 3핀 버튼 모듈 S / V / G | UNO D3 / 3.3V / GND |
| 맨몸 2핀 버튼을 쓰는 경우 | `BUTTON_MODULE=false`; UNO D3와 GND 사이 |

SG90 한 개에 5V·2A급 전원을 권장합니다. UNO USB 전원을 쓸 때 서보 외부 전원 +를 UNO 5V 핀에 함께 연결할 필요는 없으며 GND를 공통 연결합니다. 전원을 끄고 배선하고 **혼/기구물을 분리한 상태에서** 첫 TEST와 중앙 위치를 확인하세요. 실제 서보·배선·전원 동작은 아직 실물 확인이 필요합니다.

## v4의 큰 경고 동작

기존 v3의 80↔100도 짧은 동작을 **45↔135도 3회 왕복 후 90도 복귀**로 바꿨습니다. 좌우 목표는 220ms마다 바뀌며, 중앙 준비·복귀 대기를 포함한 명령 일정은 약 1.74초입니다. 실제 도달 속도·각도는 전원·부하·서보 상태에 따라 달라집니다. SG90은 각도 제어 서보이며 이 코드는 연속 360도 회전을 만들지 않습니다.

큰 움직임은 기구물에서 분리한 상태로 먼저 시험하고, 안정된 외부 5V 전원과 공통 GND를 사용하세요. 서보가 전혀 움직이지 않는 상태라면 이 변경만으로 전원·접촉·고장을 해결한 것은 아니므로 단독 시험도 필요합니다. 앱은 기존 버전을 사용하고 UNO에 v4만 업로드하면 됩니다.

HM-10 UART는 9600 baud, 8N1입니다. 앱에서 FFE0 서비스, FFE1 쓰기·Notify 특성을 사용합니다. 버튼을 쓰려면 모듈이 Notify를 지원해야 합니다.

- 앱 → UNO `TEST\n`: LED와 90→45→135→45→135→45→135→90도 동작.
- 앱 → UNO `OBSTACLE\n`: 동일한 짧은 서보 경고.
- 버튼 → 앱 `ASSIST\n`: 한 번 누를 때 한 줄 전송. 길게 눌러도 반복하지 않습니다.

하드웨어 UART를 사용해 서보 동작 중에도 수신 데이터를 처리합니다. 동작 중 추가 경고는 쌓지 않으며 버튼 요청은 서보가 움직이는 중에도 전송합니다. 길게 눌러도 반복 호출하지 않고 최소 전송 간격은 0.8초입니다. 중앙 복귀 명령 후 240ms 기다리고 펄스를 끄므로 위치 유지 토크를 보장하지 않습니다. 경고 표시용 예제이며 기구물을 강제로 움직이는 용도로 사용하지 않습니다.

길잡이 0.9.1에서 **BLE 검색 → HM-10 선택 → 선택한 BLE 기기 연결**을 누르고 앱의 TEST부터 확인합니다. 버튼으로 질문하려면 음성비서도 시작합니다. 실시간 카메라를 함께 시작하면 새 AI 보행 경고에만 `OBSTACLE`을 전송합니다. 앱이 듣는 중에 버튼을 다시 누르면 현재 답변/요청을 취소하고 다시 듣습니다. 무선이어폰은 휴대폰에 별도로 연결합니다.
